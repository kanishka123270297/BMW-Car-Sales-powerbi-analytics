# 🚗 BMW Car Sales Analysis & Insights | Power BI Dashboard

An interactive Business Intelligence project built using **Microsoft Power BI** to analyze BMW car sales, pricing trends, engine specifications, mileage, and transmission preferences across multiple models.



## 📌 Project Overview
This project explores comprehensive BMW sales data to uncover valuable business insights. It features a main overview dashboard displaying high-level Key Performance Indicators (KPIs) alongside dedicated model-specific pages for deep-dive analysis.



## ✨ Key Features & Dashboard Pages

* **Overview & Insights Page:** 
  * Displays overall KPIs including **Total Sales, Average Price, Average Mileage, Total Revenue, and Average Engine Size**.
  * Includes dedicated sections for quick model navigation and core business insights.
* **Model-Specific Dedicated Pages:** 
  * Custom pages designed for specific BMW models (**M3, i8, X3, and X6**).
* **Interactive Filters & Slicers:** 
  * Year-based timeline filters (ranging from 2010 to 2024) to track performance trends over time.
* **Visual Breakdown:** 
  * **Transmission Distribution:** Comparison between Automatic and Manual variants using donut charts.
  * **Color & Popularity Analytics:** Bar charts illustrating sales distribution across different car exterior colors.



## 📊 Key Insights Covered
1. **Model Performance:** Compare sales volume across different BMW models.
2. **Pricing Analysis:** Identify models associated with higher average price points.
3. **Engine & Mileage:** Explore correlations between engine size, mileage patterns, and sales.
4. **Customer Preferences:** Analyze market preferences for fuel types and transmission choices.



## 🛠️ Tools & Skills Used
* **Microsoft Power BI:** Dashboard creation, data modeling, and UI design.
* **DAX (Data Analysis Expressions):** Calculated measures and KPI development.
* **Data Visualization & Analysis:** Structuring interactive filters, charts, and layout hierarchies.
